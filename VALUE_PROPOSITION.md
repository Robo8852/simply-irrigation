# Value Proposition — Simply Irrigation Website

## The $3,000 Build — What He's Getting

**He's paying for custom-built software — not a template, not a drag-and-drop site.**

This is what's actually being delivered:

1. **24 custom-coded pages** — Homepage, about, contact, FAQ, testimonials, service area, 5 individual service pages, 3 blog posts, privacy policy, terms of service, sitemap, and more. Every page is hand-built, not generated from a template.

2. **Server-side rendered React application** — Built with Next.js (the same framework used by Netflix, Nike, Twitch, and Hulu). Pages load fast because they render on the server before reaching the browser. This is a level of technology that template builders like Wix and Squarespace simply do not offer.

3. **Functional contact form with email delivery** — A working server-side API endpoint that receives form submissions and delivers them as emails via Resend (a transactional email service). This isn't a mailto link or a third-party widget — it's a custom-built backend.

4. **SEO technical foundation** — The site is built with the technical infrastructure that search engines look for:
   - Structured data markup (JSON-LD schema for LocalBusiness)
   - Dynamic sitemap generation
   - Robots.txt configuration
   - Open Graph and meta tags on every page
   - Server-side rendering (Google's crawler can read everything)
   - Optimized image compression and Core Web Vitals performance

   *Note: This is the technical foundation. Search rankings depend on many factors outside anyone's control — domain age, competition, content relevance, backlinks, Google's algorithm. We're delivering the technical best practices, not guaranteeing rankings.*

5. **Google Analytics 4 integration** — Custom event tracking is wired in so he can see traffic data, where visitors come from, and what pages they view. The data is his to access.

6. **Fully responsive design** — Mobile, tablet, and desktop layouts. Custom-built with Tailwind CSS, not a template's responsive mode.

7. **Custom software at below-market pricing** — The comparable market rate for a custom Next.js website is $5,000–$15,000. Agency-built sites run $15,000–$50,000+. The $3,000 price reflects a below-market rate for what's being delivered.

## The $300/month — What He's Getting

**This is a managed service — he doesn't touch anything technical, ever.**

1. **Hosting on production infrastructure** — The site runs on Vercel's edge network with SSL (HTTPS), CDN (content delivery network), and automatic scaling. This isn't shared GoDaddy hosting — it's the same infrastructure tier used by major companies.

2. **Security & dependency maintenance** — The site is built on open-source packages that receive regular security patches. Keeping these updated is ongoing work. If a vulnerability is discovered in any dependency, it gets patched. WordPress sites that don't get this maintenance are the #1 target for hackers — custom sites with active maintenance avoid that entirely.

3. **Uptime monitoring** — If the site goes down for any reason, it gets addressed. He doesn't have to check or worry about it.

4. **Bug fixes** — If anything in the delivered functionality breaks, it gets fixed at no additional hourly cost. No support tickets, no waiting in a queue.

5. **Content updates (within monthly allowance)** — Text changes, image swaps, blog posts, phone number updates — handled by a developer who already knows the entire codebase. No learning curve, no CMS to fight with. A freelance Next.js developer charges $75–$150/hr and would need time just to understand the project before making changes.

6. **A dedicated developer who knows the system** — That's what this really is. He has someone on retainer who built the thing from scratch and can make changes quickly. That's not something you get from a template platform.

**What $300/mo breaks down to:** $10/day for hosting, security, maintenance, bug fixes, content updates, and a developer on call.
