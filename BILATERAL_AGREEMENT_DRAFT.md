## 1. Purpose

This document outlines the scope, deliverables, and terms for a custom website development and ongoing managed website service. It is intended to serve as the basis for a formal bilateral agreement to be drafted by legal counsel.

---

## 2. Project Description

The Service Provider agrees to design, develop, and manage a **custom-coded business website** using a modern, production-grade technology stack. This is **not** a template-based or CMS (WordPress/Wix/Squarespace) website — it is fully custom-built software.

The Client is engaging the Provider for an **ongoing managed website service**. The Provider retains ownership of all source code, hosting infrastructure, and deployment systems. The Client receives a fully functional, live website and the right to use it for the duration of the service agreement.

## 4. Service Scope

### 4.1 Website Pages & Features (Included in Build)
- Responsive homepage with mobile-optimized navigation
- Service pages with dynamic routing (up to 5 service detail pages)
- Blog system with individual post pages (up to 3 initial posts)
- Contact page with functional email submission form
- Legal pages (Privacy Policy, Terms of Service)
- About page

### 4.2 Technical Features (Included in Build)
- Fully responsive design (mobile, tablet, desktop)
- SEO optimization with meta tags, Open Graph, and structured data (JSON-LD schema markup)
- Google Analytics 4 integration with custom event tracking
- Contact form with server-side email delivery (Resend API)
- Server-side rendering for performance and SEO
- Optimized images and Core Web Vitals performance

### 4.3 Ongoing Managed Service (Included in Monthly Fee)
- Website hosting and deployment on Provider's infrastructure
- Uptime monitoring and availability
- Security updates and dependency maintenance
- Bug fixes for existing functionality
- Technical support via email

### 4.4 What the Client Receives
- A live, fully functional website accessible at the Client's domain
- Access to Google Analytics dashboard for traffic data
- Access to contact form submissions
- Content updates as specified in Section 6

### 4.5 What the Client Does NOT Receive
- Source code, GitHub repository, or access to the codebase
- Direct access to the hosting platform (Vercel) or deployment pipeline
- Ownership or copyright of the underlying software

## 7. Intellectual Property & Licensing

### 7.1 Ownership

The Provider **retains full ownership** of all source code, software, design assets, and technical infrastructure created for or used in this project. This includes but is not limited to:
- All application source code and configuration
- Deployment pipelines and hosting infrastructure
- Reusable components, libraries, and code patterns

### 7.2 License Grant

The Provider grants the Client a **non-exclusive, non-transferable, revocable license** to use the website for the Client's business purposes, subject to the following conditions:
- The license is active only while the Client is current on all payments
- The Client may not sublicense, resell, or distribute the website or any part of it
- The Client may not attempt to reverse-engineer, copy, or extract the source code

### 7.3 License Termination

Upon termination of this agreement (for any reason):
- The license to use the website is immediately revoked
- The Provider will take the website offline within a reasonable timeframe
- The Client has no further right to use the website, source code, or any derivative works

### 7.4 Code Buyout Option (Optional)

If the Client wishes to purchase full ownership of the source code and infrastructure at any point, the parties may negotiate a separate **Code Buyout Agreement** at a price to be determined by the Provider. This is not an obligation of the Provider.

**Legal basis:** Under 17 U.S.C. § 201(b), the Provider is an independent contractor and retains copyright by default. (See *CCNV v. Reid*, 490 U.S. 730 (1989); *JustMed v. Byce*, 600 F.3d 1118 (9th Cir. 2010); *Aymes v. Bonelli*, 980 F.2d 857 (2d Cir. 1992))
